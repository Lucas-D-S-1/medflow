O PRODUTO — MEDFLOW
--------------------
MedFlow é um painel de inteligência histórica e benchmarking externo para gestão
da saúde pública, baseado 100% em dados abertos do DATASUS (SIH/SUS + CNES).

O produto não cria dados novos. Ele processa dados públicos e os entrega em
linguagem de gestão, sem SQL, com contexto histórico e comparação entre pares.

Dois diferenciais que nenhum sistema entrega hoje:
  1. Contexto histórico: 24 meses de dados organizados em série temporal
  2. Benchmarking externo: comparação com hospitais e regiões de mesmo porte
     via DATASUS como fonte neutra


PERSONA PRIMÁRIA: SECRETÁRIO(A) DE SAÚDE
------------------------------------------
Perfil: Secretário Municipal ou Estadual de Saúde
Problema central: não sabe quais municípios e hospitais do seu território estão
no limite de capacidade — até que alguém ligue pedindo ajuda.
Precisa: visão da rede inteira, ranking de municípios por pressão, série histórica
regional, tudo sem depender de analista SQL para cada pergunta.

Persona secundária: Gestor(a) de Hospital (Diretor, Superintendente)
Usa uma view específica de "meu hospital vs. pares regionais".

Persona terciária: Analista de Saúde Pública (usuário técnico, usa Select AI).

Beneficiário final: população do SUS.


OS 5 ÍNDICES DO MEDFLOW
------------------------
Todos calculados com dados reais SIH/SUS + CNES, São Paulo, 2022–2023.

IPH — Índice de Pressão Hospitalar
  Definição: taxa de ocupação real de leitos SUS
  Fórmula: patient-days / (leitos_SUS × dias_do_mês)
  Thresholds: < 0.70 = Normal · 0.70–0.85 = Atenção · > 0.85 = Crítico
  Dados reais: Franco da Rocha: 0.939 · RS-105 (Barueri): 0.880 · Média SP: 0.44
  7.8% dos hospital-meses em SP estão em status Crítico
  CNES 2097648: IPH médio 1.01 — acima da capacidade teórica por 24 meses

IPR — Índice de Permanência Relativa
  Fórmula: permanência_média_hospital / permanência_média_regional (mesmo CID-10)
  Interpretação: IPR > 1.0 = acima da média regional · IPR < 1.0 = abaixo
  Dado real: cardio SP: 1.4× acima da média regional

IS — Índice de Sazonalidade
  Fórmula: internações_período_atual / média_histórica_mesmo_mês (últimos 2–3 anos)
  Interpretação: < 0.8 = abaixo do histórico · 0.8–1.2 = padrão normal · > 1.2 = alerta
  Dado real: Maio/Jun 2023: IS = 1.05 · Nenhum mês de 2023 ultrapassou 1.20

TMH — Taxa de Mortalidade Hospitalar
  Fórmula: SUM(MORTE=1) / COUNT(internações) × 100 — por especialidade
  Dado real: Clínica: 12.73% · UTI: 4.44% · Média SP: 5.36%
  Insight: Clínica com TMH 2.4× maior que UTI indica pressão estrutural —
  pacientes graves internados em leito clínico por falta de UTI disponível.

CMI — Custo Médio por Internação
  Fórmula: SUM(VAL_TOT) / COUNT(internações) — por especialidade (VAL_TOT > 0)
  Dado real: Cirúrgica: R$2.312 · UTI: R$2.107 · Obstétrica: R$638 · Média: R$1.670


ABORDAGEM — STORYTELLING SEM ML
---------------------------------
O produto não usa Machine Learning nem predição.
Cada indicador é apresentado em 4 camadas para o gestor:
  Camada 1: Número atual (IPH = 0.88 · Crítico)
  Camada 2: Contexto comparativo (↑ vs. mês anterior / vs. média regional)
  Camada 3: Padrão histórico ("Nos últimos 2 anos, quando IPH ficou assim...")
  Camada 4: O que significa ("Em 12 dos 23 meses críticos, o mês seguinte manteve
             ou piorou." — sem previsão, com memória.)

Ciclo de atualização: mensal, alinhado ao DATASUS (defasagem de 2–3 meses).
Para decisões estratégicas de capacidade e benchmark, mensal é suficiente.
Sprint 2 (fase futura): integração com sistemas hospitalares para granularidade diária.


FONTES DE DADOS (as 3 fontes do challenge Oracle)
---------------------------------------------------
Fonte 1 — SIH/SUS (relacional)
  Conteúdo: internações, CID-10, permanência (QT_DIARIAS), valor pago (VAL_TOT),
            mortalidade (MORTE), código hospital (CNES), município (MUNIC_MOV)
  Acesso: FTP DATASUS / pysus 2.x (.dbc → DataFrame)
  Campo-chave para IPH: QT_DIARIAS (patient-days, numerador)

Fonte 2 — CNES (JSON via API / .dbc)
  Conteúdo: leitos SUS (QT_SUS), tipo de leito (TP_LEITO), região de saúde
            (REGSAUDE), município (CODUFMUN), natureza do hospital
  Campo-chave para IPH: QT_SUS (denominador, somado por CNES × competência)

Fonte 3 — Base Populacional IBGE (CSV External Table)
  Conteúdo: estimativas populacionais por município, sexo, faixa etária
  Uso: denominador para métricas per capita (internações/1000 hab)
  Join: MUNIC_MOV (6 dígitos SIH) → CO_MUNICIPIO_IBGE (7 dígitos, prefixo 35 em SP)
